# Et mal-repo for bruk av VG2 IT i utviklerfaget.

Bruk kommandoen `npm install` første gang du bruker repoet.

Kjør kommandoen `npm start` 

Under er npm install dersom du ønsker å ta koden og bruke den andre steder

`npm install express` 

`npm install bcrypt` 

`npm install express-session` 

`npm install body-parser`
